# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and patient. People here run different hardware, editions and skill levels.
- Critique code and ideas, not people. Assume good faith.
- No harassment, insults, sexualised language or imagery, or publishing anyone's private information.
- Keep issues and pull requests on topic.

## Scope

Issues, pull requests, discussions and any other space tied to this repository.

## Reporting

Report unacceptable behaviour to the maintainer, [@NeatOuk](https://github.com/NeatOuk), through a private channel on GitHub. Reports are handled confidentially. The maintainer may edit or remove contributions, or block contributors, that break this code, following the Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).
